# TOMOE SPIN — 巴回転

円のなかに、勾玉がひとつだけ置いてある。

回すと、三つになる。

## ひとつが三つに見えるということ

画面は1秒間に決まった回数しか描き換えられない。だから
「1フレームあたり何度回るか」を 360/N に合わせると、勾玉は N か所にしか
現れなくなり、目はそれを重ねて N 個の紋として見る。

回転の速さが、紋の数を決める。

| 速度 | 現れる紋 |
|---|---|
| 180 °/frame | 二つ巴 |
| 120 °/frame | 三つ巴 |
| 90 °/frame | 四つ巴 |
| 72 °/frame | 五つ巴 |
| 60 °/frame | 六つ巴 |
| 45 °/frame | 八つ巴 |

一般に、速度を 360 で割って既約分数にしたときの**分母**が、重なって見える枚数になる。
120/360 = 1/3 だから三つ、90/360 = 1/4 だから四つ。分母が大きくなる速度
(121 °/frame など)では姿勢が散らばりすぎて紋にならず、模様は崩れて流れていく。

## なぜ勾玉なのか

姉妹作 [TAIJI SPIN](https://taiji-spin.vercel.app) の太極図を 120 °/frame で回しても、
三つ巴にはならない。太極図は円を隙間なく半分ずつ塗り分けた図形で、余白を持たない。
半分ずつの図形を3枚重ねると、どの点も必ず1枚か2枚に覆われてしまい、真っ白にも
真っ黒にもならず、全体が中間の灰色へ潰れる(2枚・4枚に至っては完全に一様な灰色になる)。

巴紋を巴紋たらしめているのは、勾玉そのものではなく**そのまわりの余白**である。
だからこの作品では、円の面積の3割ほどしか占めない勾玉をひとつだけ置いた。

勾玉は伝統的な巴紋の構図に合わせてある。頭は中心の近くに置き、
尾は縁の内側に沿って外へ巻きつきながら先細る。回転の複製が N 個
重なると、頭は中心で組み合い、尾は互いの頭を抱くように縁を巡って、
巴紋が結晶する。

## 明るさについて

現れる紋は白ではなく灰色になる。勾玉がそこに在る時間は全体の N 分の1しか
ないのだから、これは錯覚ではなく事実である。六つ巴が三つ巴より暗いのも同じ理由で、
この作品では明るさを底上げしていない。

## 操作

- **ドラッグ**:掴んで回す。離すと勢いのまま回り続ける
- **二つ〜八つ**:その紋が組める速度と形へ合わせる(キーの `2`–`8` でも)
- **速度**:−180〜180 °/frame。数値の直接入力も可
- **残像**:何フレーム分を溶かし込むか。高いほど各巴の明るさが揃う
- **巻き**:勾玉の尾が巻きこむ角度。巴の数が増えるほど浅くしないと隣とぶつかる
- **太さ**:頭の大きさ
- **鑑賞モード**(`A`):二つ巴から八つ巴まで順に巡る。紋は組み上がっては崩れ、
  また別の巴として結晶する。一周およそ90秒
- `H` パネル表示切替 / `Space` 停止 / パネルのつまみを上下スワイプで折り畳み

## 技術

- Canvas 2D・単一 HTML ファイル・依存ゼロ・完全ローカル動作
- 勾玉はオフスクリーンに一度だけ描き、毎フレームは回転して転写するだけ
- 残像は蓄積型:背景を不透明度 1−trail で塗り、その上に勾玉を重ねる
- 鑑賞モードの進行は実時間基準。60Hz でも 120Hz でも同じ速さで一周する
- モバイル:縦持ちはパネルを避けて上の余白へ、横持ちはパネルを右へ寄せる
